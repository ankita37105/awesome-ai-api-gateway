## Choosing A Gateway

Consider these factors:

- API compatibility with your current SDK
- Supported model providers
- Usage dashboard and billing transparency
- Rate limit controls
- Team and key management
- Uptime and latency requirements
- Compliance with provider terms

## Responsible Use

Use gateways only with authorized API access and permitted workloads. Do not use gateway software or hosted services to bypass provider terms, safety systems, or account restrictions.
